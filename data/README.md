# Data Directory

This directory contains all datasets, numerical outputs, reference tables, and computational artifacts used throughout the Riemann Research Workspace.

## Objectives

The purpose of this directory is to ensure that all experimental results are:

- Reproducible
- Traceable
- Auditable
- Version controlled
- Scientifically documented

Every dataset must be accompanied by sufficient metadata to allow independent verification and replication.
