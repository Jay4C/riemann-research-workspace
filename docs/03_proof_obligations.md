# Proof Obligations Register

## Purpose

Every proposed result must be decomposed into explicit proof obligations.

---

# Status Definitions

OPEN
: Not yet demonstrated.

PARTIAL
: Incomplete argument.

PROVED
: Fully demonstrated.

REFUTED
: Proven false.

BLOCKED
: Depends on unresolved results.
