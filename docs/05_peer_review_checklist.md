# Peer Review Checklist

## Mathematical Soundness

- [ ] Definitions are precise.
- [ ] Notation is consistent.
- [ ] Assumptions are explicit.
- [ ] No hidden hypotheses.
- [ ] No circular reasoning.

---

## Logical Verification

- [ ] Every implication is justified.
- [ ] Every theorem is referenced.
- [ ] Every lemma is proven.
- [ ] Edge cases are handled.
- [ ] Singularities are addressed.

---

## Analytical Verification

- [ ] Convergence justified.
- [ ] Interchange operations justified.
- [ ] Uniform bounds established.
- [ ] Error terms controlled.

---

## Computational Verification

- [ ] Code reproducible.
- [ ] Precision documented.
- [ ] Numerical errors estimated.
- [ ] Datasets archived.

---

## Literature Verification

- [ ] Citations verified.
- [ ] Dependencies identified.
- [ ] Previous work reviewed.
- [ ] Novel contribution identified.

---

## Formal Verification

- [ ] Candidate for Lean formalization.
- [ ] Candidate for Coq formalization.
- [ ] Candidate for Isabelle formalization.

---

## Publication Readiness

- [ ] Readable by specialists.
- [ ] Independent review performed.
- [ ] Counterexample search completed.
- [ ] All proof obligations closed.
